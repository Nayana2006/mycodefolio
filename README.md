# 🚀 CodeFolio – Portfolio Builder

CodeFolio is a modern and responsive **Portfolio Builder Web Application** developed using **React.js and Vite**. It helps students and developers create and manage their professional portfolio, technical skills, and projects in one place.

## 📌 Project Overview

The main objective of CodeFolio is to provide an easy-to-use platform where users can manage their:

* 👤 Portfolio information
* 💻 Technical skills
* 🚀 Development projects
* 📊 Dashboard
* 📩 Contact information

The application provides a clean and responsive user interface with easy navigation between different sections.

## ✨ Features

* 🏠 **Home Page** – Introduction to CodeFolio
* 🔐 **Login Page** – Simple login interface
* 📊 **Dashboard** – Portfolio management dashboard
* 🛠️ **Skills Management** – Add, edit, delete and search skills
* 🚀 **Projects Management** – Add, edit, delete and search projects
* 👤 **Portfolio Page** – Display profile, skills and projects
* 📩 **Contact Page** – Contact information
* 💾 **LocalStorage** – Saves skills and projects in the browser
* 🔎 **Search Functionality** – Search skills and projects
* 📱 **Responsive Design** – Works on desktop and mobile screens
* 🧭 **React Router** – Smooth navigation between pages

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/sowk6996-glitch/Portfolio-project.git
```

### 2. Navigate to the Project

```bash
cd Portfolio-project
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The application will start using the Vite development server.

## 💾 Data Storage

CodeFolio uses **Browser LocalStorage** to store skills and project information.

This allows the added skills and projects to remain available even after refreshing the browser.
